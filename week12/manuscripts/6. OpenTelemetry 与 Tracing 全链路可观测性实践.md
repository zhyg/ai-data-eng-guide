条件是服务必须处于健康状态。Phoenix 的环境变量中，DIR 文件路径应设为 data。容器内的 localhost 永远指向容器自身，因此 API 需使用服务名 otel-collector，并且版本锁定以避免冲突。 可观测性配置中定义了 Collector 的接收、处理和导出三段流水线。它首先接收 RAG API、Tool API 和 traces，转换给 Phoenix origin，然后批量发送并进行资源注入和内存限制。此外，还监听 gRPC 和 HTTP 的 OTLP，并设置了内存限制。
