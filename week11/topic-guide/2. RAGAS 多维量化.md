# 导学 02：一个「答对率」，为什么不够用？

## 一句话理解

把笼统的「答得好不好」拆成检索、生成、整体三层的多个分项指标，才能定位到底哪一环丢分。

## 用生活打比方

继续我们的学校考试体系。题库有了，接着要改进成绩单。以前只给学生一个总分，家长看不出问题在哪。现在把成绩拆成分项：审题准不准、找的资料对不对、答案有没有瞎编、有没有答到点子上。一张分项成绩单，一眼就能看出这孩子是资料没找齐，还是找齐了却答跑题。

## 关键概念

| 概念 | 大白话解释 |
| :--- | :--- |
| **三层六指标** | 把评测拆成检索层、生成层、整体层，每层看两个指标，不再只靠一个总分。 |
| **忠实度（Faithfulness）** | 答案里每句话是不是都有上下文支撑，低了说明模型在编。 |
| **相关性（Answer Relevance）** | 答案和用户问的意图贴不贴，低了说明答非所问。 |
| **精准度（Context Precision）** | 找回的资料里真正相关的占比，低了说明夹带了一堆噪声。 |
| **召回率（Context Recall）** | 该找回的关键资料实际找回了多少，低了说明漏了资料。 |
| **诊断到治疗对照** | 哪个指标低对应哪种病、该改哪里，按表精准下手，不推倒重来。 |

## 避坑提醒

- **以为总分高就是系统好**：总分把「模型编的」「答跑题」「没检索到」三种病混成一锅，定位不了问题。
- **以为忠实度和相关性一样重要**：编得有理有据能骗过用户却骗不过监管，忠实度往往是第一红线。
- **以为只看精准度就够**：只看找回来的干不干净，不看有没有漏，可能资料漏了一半分数还挺好看。
- **以为指标低就要重做整条链路**：先拆分项定位到具体一层，改一个小环节往往就能解决。

## 一句话总结

> **把质量拆成分层分项的指标，才能从「感觉不行」变成「知道哪一层该修」。**
