# 导学 01：模型答得对不对，凭什么下结论？

## 一句话理解

评测集是一套版本化、分层覆盖、能反复使用的题库，用来客观衡量模型答得好不好。

## 用生活打比方

把给模型做质检想成给一所学校建考试体系。第一步是攒一套好题库。好题库要分层：大部分考高频基础题，一部分考容易混淆的边界题，还要专门留一批陷阱题，看学生会不会被诱导写出不该写的内容，再加几道需要跨章节推理的综合题。题库要标好版本，历年错题单独存档，每道题都配好标准答案和对应的课本出处。这样明年、后年都能拿同一套题横向比。

## 关键概念

| 概念 | 大白话解释 |
| :--- | :--- |
| **评测集（数据资产）** | 把题库当成要长期经营的资产来维护，能版本化、能回归、能对抗、能治理。 |
| **四类样本** | 高频典型题（happy）、边界长尾题（boundary）、陷阱反例题（adversarial）、多跳综合题（multi-hop），少一类就有一块盲区。 |
| **反例库（Adversarial）** | 专门收集诱导越权、诱导泄露隐私、误导攻击这类题，来自踩过的坑和红队攻击，是题库里最值钱的部分。 |
| **问题-答案-证据三元组** | 每道题不只有问题和标准答案，还要标明答案该引用哪段原文当证据。 |
| **发布清单绑定（release manifest）** | 把这次发布用了哪版题库写进发布记录，锁住版本才能比较上线前后。 |

## 避坑提醒

- **以为出一次题库就一劳永逸**：业务、模型、系统底座都在变，昨天的标准答案今天可能就错了，题库要持续更新。
- **以为题多就是题好**：只堆高频题等于只考晴天，遇到陷阱题会崩，分层覆盖比数量更重要。
- **以为陷阱题可以让机器自动生成**：机器只会编晴天题，真实的诱导和攻击样本得人工补。
- **以为一道题只要问题和答案就够**：没有证据出处和分类标签，后面没法定位到底哪类题丢分。

## 一句话总结

> **先把题库做成分层、可版本、带证据的资产，后面的打分、阅卷、门禁才有立足点。**
