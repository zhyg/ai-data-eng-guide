# 导学 03：让机器当阅卷老师，它打的分能信吗？

## 一句话理解

用大模型当裁判给答案打分能省大量人工，但它有系统性偏见，必须配上评分锚点、反偏差约束、人工校准和换人对照才可信。

## 用生活打比方

继续我们的学校考试体系。分项成绩单设计好了，谁来阅卷？全靠人工太慢，于是请了一位机器阅卷老师。但这位老师有些改不掉的毛病：同一份卷子今天给的分和明天给的分不一样；排在前面的答案容易打高分；写得长的容易打高分；还偏爱和自己笔迹像的答案。这些不是换个更聪明的老师就能解决的通病。所以得给他一份带样卷的评分标准把尺子钉死，明确告诉他长短不计分，再拿一批人工判过的标准卷校准他，最后再找一位不同门派的老师一起打分互相对照。

## 关键概念

| 概念 | 大白话解释 |
| :--- | :--- |
| **大模型当裁判（LLM-as-Judge）** | 让大模型给答案打分，替代大部分人工阅卷。 |
| **四类系统性偏差** | 位置偏差、长度偏差、自我偏好、拒绝偏差，是模型架构带来的通病，得用工程手段对抗。 |
| **评分锚点** | 在打分标准里给出几档明确档位和样例，让模型不在分数区间里自由发挥。 |
| **人工校准** | 用一批人工判过的标准卷比对机器打分的吻合程度，不达标就重写打分标准。 |
| **一致性系数（Cohen's κ）** | 衡量机器和人工判断在排除随机因素后的真实吻合程度，太低就不能拿去做决策。 |
| **交叉评审（Cross-Evaluate）** | 用不同厂商的模型互相打分取共识，消除自我偏好。 |

## 避坑提醒

- **以为换个更强的模型就没偏差**：模型越强偏差越隐蔽，位置和自我偏好是架构通病，还得靠工程手段。
- **以为写好打分提示词就够了**：没有人工校准的分数和算命差不多，改了打分标准等于换了裁判，必须重新校准。
- **以为用同一个模型生成又打分很省事**：模型偏爱自己的风格，分数会虚高，裁判和选手不能是一家。
- **以为打分就是给个数字**：好的裁判还要说清扣分理由和哪些说法没有支撑，这些能回流到反例库。

## 一句话总结

> **机器阅卷省成本的前提，是先用人工标准卷把它校准到可信，再换人对照。**
