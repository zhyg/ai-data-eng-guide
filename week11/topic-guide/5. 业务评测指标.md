# 导学 05：技术分很漂亮，老板为什么还是不买账？

## 一句话理解

把技术指标顺着一条漏斗翻译成业务结果和合规红线，让上线决策也要过业务这一关。

## 用生活打比方

继续我们的学校考试体系。分项成绩再好看，校长和家长真正关心的是升学率、就业率这些结果。从卷面分高到考上好学校，中间隔着好几环：题答得好，学生得真的听懂，听懂得转化成好的应试表现，最后才落到录取。中间任何一环卡住，分数涨了升学率也不动。还有些是红线，比如考场作弊，一次都不能有，性质和多考几分完全不同。

## 关键概念

| 概念 | 大白话解释 |
| :--- | :--- |
| **业务漏斗** | 技术指标要经过质量、用户行为、业务流程几环，才变成自助率、满意度这类业务指标。 |
| **业务 SLO** | 业务方设定的目标，比如一次解决率、工单闭环率、每单成本，达不到只能内测不能正式上线。 |
| **合规红线** | 合规拦截、误导率、隐私泄露、引用覆盖这类指标，是过线还是出局，和越高越好的质量指标不同。 |
| **风控域指标** | 风控评测看的是判得对不对，用一套完全不同的指标衡量能不能区分好坏、会不会误杀。 |
| **区分能力与漂移（AUC / KS / PSI）** | AUC 和 KS 看模型区分好坏的能力，上线前看；PSI 看数据分布有没有偏移，上线后天天看，是该不该重训的信号。 |

## 避坑提醒

- **以为技术分涨了业务就会涨**：中间漏斗任何一环卡住，业务指标都可能不动，要追端到端的结果。
- **以为合规指标和质量指标一样管理**：质量是越高越好，合规是过线出局，得单独用红线和告警管。
- **以为风控和客服能用同一套指标**：风控是离散决策，错一次就是资金损失，评测比客服严得多。
- **以为模型区分能力高就能上线**：区分能力再高，如果误杀成本把收益吃光，业务上照样是亏的。

## 一句话总结

> **把业务 SLO 和合规红线绑进发布清单，上线决策才既看技术分也看业务和合规。**
