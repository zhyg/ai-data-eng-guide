# 导学 05：技术分很漂亮，老板为什么还是不买账？

## 一句话理解

把技术指标顺着一条漏斗翻译成业务结果和合规红线，让上线决策也要过业务这一关。

## 用生活打比方

继续我们的学校考试体系。分项成绩再好看，校长和家长真正关心的是升学率、就业率这些结果。从模拟考高分到最终录取，中间隔着好几环：模拟考得好，正式考试要正常发挥，正式成绩出来要过投档线，面试还得通过。中间任何一环卡住，模拟分涨了录取率也不动。还有些是红线，比如考场违纪，一次就取消资格，性质和多考几分完全不同。

## 关键概念

| 概念 | 大白话解释 |
| :--- | :--- |
| **业务漏斗** | 技术指标要经过质量、用户行为、业务流程几环，才变成自助率、满意度这类业务指标。 |
| **业务 SLO** | 业务方设定的目标，比如一次解决率、工单闭环率、每单成本，达不到只能内测不能正式上线。 |
| **合规红线** | 合规拦截、误导率、隐私泄露、引用覆盖这类指标，是过线还是出局，和越高越好的质量指标不同。 |
| **风控域指标** | 风控评测看的是判得对不对，用一套完全不同的指标衡量能不能区分好坏、会不会误杀。 |
| **AUC / KS** | 衡量模型区分好坏的能力，比如能不能把该拦的和不该拦的分开，上线前看。 |
| **PSI（分布漂移）** | 当前数据分布和训练时的差距有多大，上线后天天看，是该不该重训的信号。 |

## 避坑提醒

- **以为技术指标涨了就是业务变好了**：中间漏斗任何一环卡住，业务指标都可能不动，要追端到端的结果。
- **以为合规指标和质量指标是一回事**：质量是越高越好的连续优化，合规是过线出局的二值红线，得单独管。
- **以为客服和风控能共用一套评测标准**：风控是离散决策，错一次就是资金损失，评测比客服严得多，指标体系完全不同。
- **以为区分能力高就是可以上线**：区分能力再高，如果误杀成本把收益吃光，业务上照样是亏的。

## 一句话总结

> **把业务 SLO 和合规红线绑进发布清单，上线决策才既看技术分也看业务和合规。**
